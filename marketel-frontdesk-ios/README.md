# Marketel Front Desk for iOS

This is an isolated Capacitor shell used to dogfood the live Marketel Front
Desk on an iPhone before the App Store release.

The test build loads:

`https://guest-lodge-backend.onrender.com/frontdesk?native=ios`

Version 2 adds native iOS navigation around the hosted Front Desk, including
the system tab bar, property switching, and a compact native Guest App tools
screen. On iOS 26 the standard UIKit navigation receives the system Liquid
Glass appearance automatically.

It does not replace the existing PWA and does not yet register for native APNs
notifications. The existing browser Web Push flow should still be tested
through the Home Screen PWA.

## Install through AltStore Classic

1. Open the repository's **Actions** tab and select **Build Marketel iOS IPA**.
2. Open the latest successful run and download the `Marketel-Front-Desk-IPA`
   artifact.
3. Unzip the artifact and open `Marketel-Front-Desk.ipa` with AltStore.

The optional `altstore-source.json` file is updated to point at tagged GitHub
Release builds when a release is published.

## Local project refresh

The committed `ios/` project is generated by Capacitor. After changing native
dependencies or configuration:

```sh
npm ci
npm run sync
```

Building the IPA requires Xcode, so CI uses a GitHub-hosted macOS runner.
