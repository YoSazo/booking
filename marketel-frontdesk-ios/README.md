# Marketel Front Desk for iOS

This is the native iOS companion for active Marketel customers. It combines a
Front Desk bundled inside the IPA with native navigation, property switching,
contact creation, account deletion, and Apple Push Notification service booking
actions. Authenticated data still comes from the Marketel HTTPS API.

The shell uses four primary tabs and places Revenue inside Bookings. It only
admits properties with an active Marketel subscription. Subscription purchase
and billing management are intentionally unavailable in the iOS app. On iOS 26
the UIKit navigation uses the system Liquid Glass appearance automatically.

Existing owner PWA installs remain supported, but new owners are directed to the
Marketel Front Desk App Store app. Guests never download Marketel Front Desk;
they save the individual property's booking page to their Home Screen. Both
owner clients use the same backend and property data, while the iOS HTML,
JavaScript, CSS, fonts, and icons are packaged with the app rather than executed
from a third-party CDN.

## Install through AltStore Classic

1. Open the repository's **Actions** tab and select **Build Marketel iOS IPA**.
2. Open the latest successful run and download the `Marketel-Front-Desk-IPA`
   artifact.
3. Unzip the artifact and open `Marketel-Front-Desk.ipa` with AltStore.

The unsigned workflow is for device testing. Native APNs requires a paid Apple
Developer team, a push-enabled App ID, an APNs key on the backend, and a signed
profile containing the push entitlement.

## TestFlight and App Store archive

The `Release Marketel Front Desk to TestFlight` workflow creates a signed
App Store archive. Configure the secrets listed in
`app-store/submission-checklist.md`, then run the workflow manually. Leave
`upload_to_testflight` off to validate signing and download the archive artifact;
turn it on to send the build to App Store Connect.

Store listing copy, review notes, privacy-label guidance, and the screenshot
plan live in `app-store/`.

## Local project refresh

The committed `ios/` project is generated by Capacitor. After changing the
Front Desk or native configuration:

```sh
cd ../guest-lodge-backend/frontdesk
npm ci
npm run build:native
cd ../../marketel-frontdesk-ios
npm ci
npm run sync
```

Building the IPA requires Xcode, so CI uses a GitHub-hosted macOS runner.
