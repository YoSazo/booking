# Owner assets

Place your own testimonial screenshots, portrait, product recording stills and
genuine media/credential images here. Configure their paths and text in
`../content.js`. Use `/payoff/assets/<filename>` paths, meaningful alt text and
only material you have permission to publish. No reference-vendor assets ship.

The local preview has 15 testimonial placements in groups of 2 / 2 / 4 / 7.
Four reuse those entries on the order page. Missing images are omitted.
